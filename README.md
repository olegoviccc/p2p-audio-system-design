# p2p-audio-system-design

Проектирование звука для объектов P2P. Репозиторий переименован 24.11.2026
(бывший `teplica`); старые ссылки GitHub редиректятся.

## Проекты

- [Теплица](teplica/README.md) — кафе, три зоны; варианты A / A2 / B / C,
  сметы, схемы и PDF для согласования.
- [Бар «Продукты»](produkty/README.md) — Санкт-Петербург, 9-я линия В.О., 60,
  лит. А; предварительный проект на три зоны: зал 4×KEF Q350, гардероб,
  санузел; смета, план покрытия и эскиз потолочного подвеса.
