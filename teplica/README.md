# Теплица: звуковая система

В работе [вариант A](A-kef-volta-sub/README.md). Источник — iPad. Зал, улица и туалет получают одну программу с независимой регулировкой громкости.

- **Зал:** четыре KEF Q350 Walnut, усилитель Volta LIVE 4.400.
- **Улица:** белая CVGaudio OSR608TW на отдельном Lab.gruppen CA1201.
- **Туалет:** потолочная CVGaudio CRH608T на отдельном Lab.gruppen CA1201.
